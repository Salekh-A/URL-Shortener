# URL Shortener

Сервис сокращения ссылок на Go с in‑memory storage, структурированным логированием и тестами.

## Возможности

- Создание короткой ссылки (POST /)
- Редирект по короткой ссылке (GET /{id})
- Конфигурация через флаги и переменные окружения
- Логирование запросов (метод, путь, статус, время, размер)

## Запуск

```bash
go run cmd/main.go
